プライバシーポリシー / Privacy Policy

listing-manager は、許可をいただいた eBay アカウントの出品を管理する、個人用のツールです。
listing-manager is a personal tool that manages the listings of the eBay account whose owner has authorized it.

取り扱う情報 / Data handled

  • 出品ID、オファーID、SKU、価格、仕入れ元のURL / Listing IDs, offer IDs, SKUs, prices, and source URLs
  • 許可の証明（アクセストークン・リフレッシュトークン）。第三者に公開しない、非公開の保管場所にのみ保存します。 / Authorization tokens, stored only in private secret storage and never shared

取り扱わない情報 / Data not handled

購入者の氏名・住所・連絡先などの個人情報は、取得も保存もしません。注文のデータは扱いません。
The tool does not retrieve or store buyers' personal information (names, addresses, contact details) and does not handle order data.

第三者への提供 / Sharing

情報を第三者に提供・販売しません。 / Data is not shared with or sold to third parties.

許可の取り消し / Revoking access

eBay のアカウント設定の、アプリへの許可の管理から、いつでも取り消せます。
You can revoke access at any time from your eBay account's app permission settings.
